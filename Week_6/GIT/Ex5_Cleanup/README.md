# Git Exercise 5: Cleanup and Push to Remote

## Steps Demonstrated

### Step 1: Verify clean state
```bash
git status
```

### Step 2: List all branches
```bash
git branch -a
```

### Step 3: Pull from remote
```bash
git pull origin master
```

### Step 4: Push pending changes
```bash
git push origin master
```

### Step 5: Verify remote
```bash
git log --oneline -5
# Check that commits are reflected in remote repository
```
